#Bonhomia Lingerie
Descripción
Bonhomia Lingerie es un sitio web desarrollado como proyecto de Pre-Entrega del curso de Front-End, aprovechando que es un emprendimiento que estoy comenzando!

El sitio presenta una colección de productos de lencería femenina, incluyendo una sección de productos, reseñas de clientas, contenido multimedia y un formulario de contacto funcional mediante Formspree.

Tecnologías utilizadas:
HTML5
CSS3
Flexbox
CSS Grid
Media Queries
Google Fonts
Formspree
Características:
Diseño responsive para dispositivos móviles y escritorio.
Catálogo de productos con tarjetas visuales.
Sección de reseñas.
Video integrado mediante iframe.
Formulario de contacto funcional.
Navegación interna por secciones.
